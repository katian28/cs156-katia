# Study Materials

Local study resources that don't get committed to git.

Use this folder for:
- Downloaded PDFs and ebooks (Murphy, Barber, Bishop, etc.)
- Video recordings or notes from class
- Personal study notes and scratch work
- Reference materials and cheat sheets
- Datasets and data files
- Any large or personal files

Everything in this folder is ignored by git (see .gitignore), so you can store materials locally without cluttering the repository.

## Organization Suggestion

```
study_materials/
├── readings/
│   ├── murphy_ch3.pdf
│   ├── murphy_ch7.pdf
│   └── ...
├── videos/
│   ├── 3blue1brown_essence_of_linear_algebra/
│   └── statquest_multiple_regression.mp4
├── notes/
│   ├── session_1_notes.txt
│   ├── session_2_notes.txt
│   └── session_3_notes.txt
├── datasets/
│   ├── titanic.csv
│   └── iris.csv
└── scratch/
    ├── derivations.txt
    └── practice_problems.txt
```

No files here will be tracked by git.
