## How to Use This Folder

1. **Before each session**: Read the relevant chapter from Murphy
2. **Pre-class work (PCW)**: Complete problems and code before class
3. **During class**: Participate in activities and breakout groups
4. **After class**: Review notes and prepare for next session

## Course Structure

**Unit 0: ML Fundamentals** (Session 1)
- What is ML, basic pipeline, overview of algorithms

**Unit 1: Core Mathematics** (Sessions 2-10)
- Linear algebra, basic models, neural networks, gradients, validation

**Unit 2: High-Dimensional Data** (Sessions 11-21)
- Overfitting, bias-variance, advanced models, dimensionality reduction

**Unit 3: Generative Models** (Sessions 22-25)
- Hidden Markov models, transformers, attention, LLMs
